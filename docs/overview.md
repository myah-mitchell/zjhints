# Documentation overview

The pages in this directory, and what each one is for. Start with the [configuration reference](configuration.md) if you are looking for a specific option, or with the [README](../README.md) if you have not installed the plugin yet.

| Page | What it covers |
| --- | --- |
| [Configuration](configuration.md) | Every option the plugin reads, with its default |
| [Hints](hints.md) | Where hints come from: the curated list, discovery, and shared bindings |
| [Labels](labels.md) | Ids, renaming and hiding hints, per-mode labels, and merging two hints into one |
| [Keys and ordering](ordering.md) | Which keys a hint shows, and the order of both keys and hints |
| [Styling](styling.md) | Format strings, colors, per-hint styling, and key, modifier and chord aliases |
| [Fitting the bar](fitting.md) | Fitting the line to the terminal, choosing what gets dropped, and marking the gap |
| [Nested sessions](nested-sessions.md) | Running one Zellij session inside another, and running this plugin in its own pane |
| [Automation](automation.md) | How the repository builds, tests, updates itself and publishes, and the setup GitHub needs |

Automation is for anyone maintaining a copy of the repository. The rest are for anyone configuring the plugin.
